# GPT4All

### Run powerful AI models locally on any hardware

GPT4All is an open-source ecosystem for running large language models locally on your CPU or GPU. With a simple desktop interface, a growing model library, and optional local document chat, it's AI for everyone.

<br>

---

## Features

| | |
|:---|:---|
| **CPU-Friendly** | Optimized models run smoothly on ordinary laptops without a GPU |
| **LocalDocs** | Chat with your local files and folders using retrieval-augmented generation |
| **Model Explorer** | Browse and download curated models from the built-in library |
| **Open Ecosystem** | Fully open-source, with an active community of contributors |
